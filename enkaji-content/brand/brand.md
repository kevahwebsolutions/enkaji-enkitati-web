# Brand

Logo: Maasai enkaji (house) dome in forest green; a gold path a girl walks with a book toward a rising sun; cream and gold bead-diamond band; serif wordmark "ENKAJI ENKITATI CBO"; tagline "Empowering Women, Sustaining Futures".

| Token | Hex | Use |
|---|---|---|
| --primary (forest green) | #1C380E | header, headings, primary buttons, footer bg |
| --primary-soft | #2E5A1C | hover, links |
| --accent (harvest gold) | #C4A050 | donate button fill, icons, dividers (never text on white) |
| --accent-ink (deep gold) | #7A5C22 | gold text on light backgrounds |
| --bead (cream) | #EEE3C4 | pattern fills, card tints |
| --sand | #F7F1E1 | section backgrounds |
| --ink | #1C1A17 | body text |

Contrast (measured): green/white 13.0, green/sand 11.5, green text on gold 5.2, deep gold/sand 5.5, gold/white 2.4 (decorative only).
Donate button = gold fill + green text. Light theme only.

Type: headings Libre Baskerville (or Cormorant Garamond 600) mixed case; eyebrow labels spaced caps in the same serif; body Inter. Load with next/font.
Imagery: no stock photos of people. Until real photos arrive use illustrated / bead-pattern placeholders.
